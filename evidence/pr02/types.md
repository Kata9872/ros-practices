# Анализ типов и топиков

* **Целевой топик**: `/turtle1/cmd_vel`
* **Тип сообщения**: `geometry_msgs/msg/Twist`
* **Структура Twist**: Содержит два трехмерных вектора `Vector3` — `linear` (x, y, z) для поступательного движения и `angular` (x, y, z) для вращения.
* **Эксперимент**: При публикации в `/cmd_vel` подписчик отсутствует, так как turtlesim подписывается исключительно на неймспейс конкретной черепахи (`/turtle1/cmd_vel`).
