# Разбор команд Linux для ПР02

1. `source /opt/ros/jazzy/setup.bash` — выполняет скрипт настройки окружения в текущей оболочке терминала, загружая пути и переменные ROS 2.
2. `colcon build --symlink-install` — компилирует и собирает ROS 2 пакеты в текущем воркспейсе, создавая симлинки на ресурсы для быстрой разработки.
3. `mkdir -p evidence/pr02` — создает структуру каталогов (включая родительские при необходимости) без ошибки, если директория уже существует.

## Ответы на вопросы
* **Отличие `>` от `|`**: `>` перенаправляет стандартный вывод (stdout) в файл на диске, перезаписывая его. Оператор `|` (pipe) перенаправляет стандартный вывод одной программы на стандартный ввод (stdin) другой программы.
* **Отличие `source` от запуска новой программы**: Обычный запуск команды/скрипта создает отдельный дочерний процесс, переменные которого исчезают после завершения. Команда `source` выполняет файл прямо в контексте текущей оболочки терминала, сохраняя все экспортированные переменные среды.
